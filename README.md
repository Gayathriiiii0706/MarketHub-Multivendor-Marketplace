MarketHub – Multivendor E-commerce Marketplace

MarketHub is a multivendor e-commerce web application that allows customers to browse products, manage their shopping cart, and place orders. Vendors can manage their products and view orders through a vendor dashboard.

This project was developed to practice frontend development, Python backend development, REST APIs, and database integration.

Features

- Product listing and product details
- Product search and browsing
- Shopping cart and checkout
- Customer registration and login interface
- Vendor dashboard and product management
- Admin dashboard
- Order placement and order history
- Django REST API backend
- AI-assisted product description generation using Ollama

Technologies Used

Frontend

- HTML5
- CSS3
- JavaScript

Backend

- Python
- Django
- Django REST Framework

Database

- Oracle SQL

AI Integration

- Ollama with a locally running language model

Getting Started

1. Clone the repository

git clone https://github.com/Gayathriiiii0706/MarketHub-Multivendor-Marketplace.git

2. Open the project folder

Open the downloaded project folder in your code editor.

3. Run the frontend

Open "index.html" using a local development server, such as the VS Code Live Server extension.

4. Set up the backend

- Install Python.
- Create and activate a virtual environment.
- Install the required Python packages.
- Configure the database connection using your local environment variables.
- Run the Django development server.

Refer to the Django documentation for environment and server setup.

5. Optional AI setup

If using the AI product description feature, install Ollama, download a compatible model, and start the local Ollama service.
